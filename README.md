# Xiaomi Mi A2 Lite / Redmi 6 Pro  
_Codenames: `daisy`, `sakura`_

The **Xiaomi Mi A2 Lite** (also known as **Redmi 6 Pro**) is a mid-range smartphone released by Xiaomi in **July 2018**. It shares the same hardware under different branding depending on the region.

---

## Device Specifications

| Feature              | Specification                                |
|----------------------|----------------------------------------------|
| **Device Name**      | Xiaomi Mi A2 Lite / Xiaomi Redmi 6 Pro       |
| **Codename**         | `daisy` / `sakura`                           |
| **SoC**              | Qualcomm MSM8953 Snapdragon 625              |
| **CPU**              | Octa-core 2.0 GHz Cortex-A53                 |
| **GPU**              | Adreno 506                                   |
| **RAM**              | 3 GB / 4 GB                                  |
| **Storage**          | 32 GB / 64 GB                                |
| **Battery**          | Non-removable Li-Po 4000 mAh                 |
| **Dimensions**       | 149.3 × 71.7 × 8.8 mm                        |
| **Display**          | 5.84" IPS LCD, 1080 × 2280 (~432 ppi)        |
| **Rear Camera 1**    | 12 MP, f/2.2, 1.25 μm, PDAF                  |
| **Rear Camera 2**    | 5 MP, f/2.2, 1.12 μm, depth sensor           |
| **Front Camera**     | 5 MP, f/2.0                                  |
| **Shipped Android**  | Android 8.1 Oreo                             |
